# AI Agent 实践项目
> 个人学习实践｜2026.07‑2026.08，实习过程中基于AI平台完成的多场景智能体工具开发。

## 📌项目背景
实习期间参与AI智能体平台版本测试、大模型测评工作，同时面向不同用户场景独立搭建多款智能体原型工具。
> ⚠️本仓库为个人实践Demo，**不包含公司内部代码、内部业务文档**。
> 所有配置文件中的真实API密钥已替换为占位符，需要使用者自行复制`.env.example`生成`.env`，填入自己的API凭证。
> 桌面宠物生成器仅提供Electron源代码，**不附带编译后的exe可执行程序**，需要本地npm打包生成客户端。

## ✨智能体列表
1. **塔罗占卜智能体**：支持详细占卜、快速占卜、今日运势，交互式抽卡+AI解读 → [tarot‑sage](./tarot‑sage)
2. **短视频脚本生成器**：输入主题、平台、风格，输出多版脚本，附带标题、分镜表、音效、封面建议 → [video‑script‑generator](./video‑script‑generator)
3. **电脑桌宠生成器**：图片去背景，生成可拖拽互动桌面宠物（Electron） → [desktop‑pet‑generator](./desktop‑pet‑generator)
4. **虚拟职业规划师**：简历岗位差距分析、MBTI+霍兰德测评，生成5年职业发展路径，支持多格式导出 → [career‑planner](./career‑planner)

## 📝实践内容
1. 智能体开发：工作流编排、交互设计、功能迭代、自测调优，完成多套原型。
2. 大模型测评实践：对比多款视频生成大模型，从清晰度、画幅、动作连贯性评估模型业务适配性。
3. 平台测试实践：参与功能、回归、兼容性测试，积累AI产品测试经验。

## 📂目录说明
- `agents`：智能体脱敏工作流配置模板
- `docs`：实践复盘文档、大模型测评总结
- `assets`：项目运行效果截图
- `tarot‑sage`：塔罗占卜智能体完整源码
- `video‑script‑generator`：短视频脚本生成器完整源码
- `career‑planner`：职业规划智能体完整源码
- `desktop‑pet‑generator`：Electron桌宠生成器源码

### 本地运行简要提示
1. 将对应项目目录下 `.env.example`复制一份，重命名为 `.env`，填入自己的API Key。
2. 执行 `npm install`安装依赖，再启动服务；桌宠项目执行`npm run build`完成本地打包。
