# AI Agent 实践项目
> 个人学习实践｜2025.07‑2025.08，实习过程中基于AiPy平台完成的多场景智能体工具开发。

## 📌项目背景
实习期间接触AI智能体平台，完成版本测试、大模型测评，同时面向不同用户场景独立搭建多款智能体工具。
> ⚠️本仓库为个人实践Demo，**不包含公司内部代码、内部业务文档**，仅存放智能体工作流配置与复盘文档。

## ✨智能体列表
1. 塔罗占卜智能体：支持详细占卜、快速占卜、今日运势，交互式抽卡+AI解读
2. 短视频脚本生成器：输入主题、平台、风格，输出多版脚本，附带标题、分镜表、音效、封面建议
3. 电脑桌宠生成器：图片去背景，生成可拖拽互动桌面宠物
4. 虚拟职业规划师：简历岗位差距分析、MBTI+霍兰德测评，生成5年职业发展路径，支持多格式导出

## 📝实践内容
1. 智能体开发：工作流编排、交互设计、功能迭代、自测调优，部分部署本地集市使用
2. 大模型测评实践：对比多款视频生成大模型，从清晰度、画幅、动作连贯性评估模型业务适配性
3. 平台测试实践：参与功能、回归、兼容性测试，积累AI产品测试经验
