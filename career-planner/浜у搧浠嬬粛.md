# 虚拟职业规划师 - 产品介绍
## 一、产品概述
虚拟职业规划师是一款基于AI大模型的职业规划智能体，通过科学的测评工具和AI深度分析，帮助用户：
- 了解自己与目标岗位的真实差距
- 探索个性化的职业发展路径
- 发现隐藏的职业潜能和机会
## 二、核心功能
### 1. 差距分析
**功能描述**：上传简历或粘贴内容，AI分析你与目标岗位的差距，生成五维报告。
**报告内容**：
- 综合匹配度评分（1-100分）
- 岗位核心需求拆解（3-5个要点）
- 您的匹配项分析（优势梳理）
- 关键差距项分析（按重要性排序）
- 弥补差距的行动方案（可操作建议）
**适用场景**：求职者评估岗位匹配度、在职员工规划跳槽方向。
### 2. 职业综合分析
**功能描述**：结合MBTI人格测试（20题）、霍兰德职业兴趣测试（6题）和职业探索问卷（5题），AI生成三条差异化5年职业发展路径。
**报告内容**：
- 人格与兴趣画像分析
- 三条职业路径（技术深耕/管理晋升/跨界转型）
- 每条路径含分年度里程碑、薪资范围、能力补充、风险提示
- 综合建议（推荐最适合的路径）
**适用场景**：职场新人规划发展方向、在职员工考虑晋升或转型。
### 3. 职业探索雷达
**功能描述**：通过5个精心设计的问题，AI挖掘用户的隐藏潜能，推荐冷门但匹配的职业方向。
**报告内容**：
- 五维度潜力评估（技术性/创意性/管理性/服务性/商业性）
- 3个冷门职业方向推荐
- 下一步行动建议
**适用场景**：对未来方向迷茫、想探索新可能性的用户。
## 三、产品特点
### 1. AI驱动
所有分析基于AI大模型，提供专业、个性化的建议，而非模板化内容。
### 2. 科学测评
融合MBTI人格理论和霍兰德职业兴趣理论，分析更有依据。
### 3. 结果导向
报告直接给出评分、差距项、行动方案，用户看完知道下一步做什么。
### 4. 操作简单
全程5分钟，无需注册，填写信息即可获得报告。
### 5. 多端适配
支持PC和移动端，界面简洁美观，蓝白配色清爽舒适。
### 6. 主题切换
支持浅色/深色模式，满足不同用户偏好。
### 7. 报告导出
支持一键复制、导出MD/Word/PDF格式，方便保存和分享。
## 四、适用人群
- **求职者**：想了解自己与目标岗位的差距
- **职场新人**：入行1-3年，方向迷茫
- **在职员工**：工作3-5年，想晋升或转型
- **转行者**：想跨行业，需要了解自己的优势
- **学生群体**：即将毕业，想提前规划职业方向
## 五、技术架构
- **前端**：HTML + CSS + JavaScript（单页应用）
- **后端**：Node.js + Express
- **AI接口**：OpenAI兼容的Chat Completions接口
- **文件解析**：multer + mammoth + pdf-parse
- **部署方式**：npm start，随机端口启动，支持多用户
