# 虚拟职业规划师 - 使用说明
## 一、项目简介
虚拟职业规划师是一款AI驱动的职业规划工具，帮助用户科学规划职业发展。通过差距分析、职业综合分析等功能，为用户提供个性化的职业发展建议。
## 二、环境要求
- Node.js 18.0 及以上版本
- npm 或 yarn 包管理器
## 三、快速启动
### 1. 安装依赖
```bash
cd career-planner
npm install
```
### 2. 启动服务
```bash
npm start
```
### 3. 访问服务
服务启动后，终端会输出随机端口信息：
```json
{"type": "http_start", "port": 52613}
```
在浏览器中访问：`http://localhost:52613`（端口以实际输出为准）
## 四、功能使用指南
### 功能一：差距分析
1. 点击左侧导航栏"差距分析"
2. 上传简历文件（支持 .docx / .pdf / .txt，最大10MB）或粘贴简历全文
3. 粘贴目标岗位JD
4. 点击"开始分析"按钮
5. 等待AI生成五部分报告：
   - 综合匹配度评分（1-100分）
   - 岗位核心需求拆解
   - 您的匹配项分析
   - 关键差距项分析
   - 弥补差距的行动方案
6. 报告支持一键复制、导出MD/Word/PDF
### 功能二：职业综合分析
1. 点击左侧导航栏"职业综合分析"
2. 填写基本信息（年龄、行业、当前岗位、核心技能、职业目标）
3. 完成MBTI人格测试（20题）
4. 完成霍兰德职业兴趣测试（6题）
5. 完成职业探索问卷（5题）
6. 点击"开始AI分析"
7. 获取三条差异化5年职业发展路径及综合建议
### 功能三：主题切换
- 点击左下角的 🌙/☀️ 按钮，切换浅色/深色模式
- 主题选择会自动保存，下次打开保持
## 五、AI接口配置
AI接口使用OpenAI兼容的Chat Completions接口。配置从 `config.js` 读取，避免硬编码API Key。
### 首次使用配置
1. 复制 `config.example.js` 为 `config.js`
2. 编辑 `config.js`，填写{{API_KEY}}：
```javascript
module.exports = {
  AI_BASE_URL: 'https://api.trustoken.cn/v1',
  AI_API_KEY: '{{API_KEY}}',
  AI_MODEL: 'auto'
};
```
3. 保存后启动服务即可
> ⚠️ 注意：`config.js` 包含{{API_KEY}}，已被 `.gitignore` 排除，不会上传到GitHub
## 六、常见问题
### Q1: 服务启动失败，提示端口被占用
服务使用随机端口启动，不会冲突。如果遇到问题，请检查是否有其他进程占用端口。
### Q2: AI分析超时
AI调用默认超时时间为90秒。如果网络较慢，请耐心等待。
### Q3: 文件上传失败
支持 .docx / .pdf / .txt 格式，文件大小不超过10MB。请确认文件格式正确。
### Q4: 如何停止服务
在终端按 Ctrl+C，服务会优雅退出。
