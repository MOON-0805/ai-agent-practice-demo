# AI智能体开发复盘

## 项目概述

基于AI平台搭建4个不同场景智能体原型，覆盖占卜、脚本生成、职业规划、桌面客户端。

## 开发思考

1. **Prompt设计**：区分系统提示词、用户输入，处理大模型幻觉，增加输出格式约束。
2. **异常场景思考**：空输入、非法输入、超长文本输入，思考边界 case。
3. **自测调优**：反复迭代工作流分支逻辑，优化输出稳定性。

## 遇到问题与解决

1. **大模型输出格式不稳定**：增加输出 json 格式强制约束，增加校验分支。
2. **上下文过长**：增加上下文截断策略。

## 可优化方向

- 增加结果缓存
- 增加更多异常兜底分支
