# 大模型测评实践总结

> 本报告为个人学习实践，不涉及公司业务数据。

## 测评目标

对比多款大模型在内容生成、指令遵循、格式输出场景表现，评估业务适配能力。

## 测评维度

1. **指令遵循能力**：是否严格按照要求输出格式
2. **输出稳定性**：相同输入多次输出结果一致性
3. **边界鲁棒性**：空输入、模糊提问、越界提问处理
4. **幻觉问题**：是否编造虚假信息

## 测评方法

构造正向用例、边界用例、异常用例，记录现象，归纳模型优缺点。

## 收获

学习AI产品测试思路：大模型测试和传统软件测试差异；输出不只有 pass/fail，需要记录现象、复现条件。
