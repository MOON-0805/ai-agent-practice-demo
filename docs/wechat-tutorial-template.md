# AI智能体公众号推文&用户教程产出框架

> 适用：小众AI工具，面向小白、普通使用者；两种文章模式：【使用已有上架智能体】、【手把手制作同款智能体】

## 🎯推文核心目标

1. 对未下载产品的读者：唤起兴趣，引导下载产品
2. 对已有产品的普通用户：完整跑通整套操作流程，解决开篇提出的业务痛点，把智能体用得更好

> 人群策略：一篇文章同时覆盖小白+普通使用者；小白侧保证步骤完整连贯，普通使用者重点聚焦痛点解决方案；行文、案例不做两套独立版本。

## 📑固定文章结构（你的现有成熟结构）

1. **开头：痛点场景引入+效果展示（前置效果图，抓住读者注意力）**
   - 形式：场景描述 / 灵魂拷问，还原大部分用户真实遇到的困境，制造用户共鸣
   - 紧接着：效果展示截图，直观展示最终能拿到的结果，留住读者

2. **价值预览：列出可解决的问题 + 智能体对应的解决方案**
   > 告诉读者看完这篇可以收获什么，建立预期，让读者愿意往下阅读完整流程

3. **正文干货（二选一，两种推文模式）**

   > 模式A｜教程：使用平台已经上架的智能体解决问题
   > 1）收集平台官方对该智能体的基础介绍
   > 2）本人完整实操全流程，逐步骤截图，图片按步骤命名编号
   > 3）输入素材包：智能体介绍 + 全套步骤截图 + 过往同风格推文样例，交给AI生成3版Markdown格式推文备选，图片位置预留截图占位
   > 4）人工筛选、校对、润色，保证第一人称使用者口吻，步骤连贯详细，避免晦涩术语

   > 模式B｜教程：手把手教你提示词制作同款智能体
   > 1）撰写完整分点原始提示词，交给AI生成初版智能体
   > 2）多轮迭代优化提示词，记录每一轮优化指令
   > 3）记录实操过程遇到的坑、对应的可复现解决方案
   > 4）整理素材：原始提示词、迭代优化提示词、踩坑记录、成品效果截图
   > 5）给到AI生成推文，输出3版Markdown备选，人工校对修改，保留个人实操口吻

4. **踩坑与解决方案模块（标题统一：踩坑与解决方案（帮你省时间））**
   - 数量：4‑6条
   - 问题来源：本人实操踩坑、AI推演的合理问题、少量内部反馈
   - 每条格式：`现象描述 → 可复现的操作步骤 → 具体解决方案`

5. **结尾引导**
   - 附上产品邀请链接、粉丝社群入口，邀请读者交流使用感受

## 📝案例与素材选取原则

1. 全部案例来源于本人真实实操，不虚构案例
2. 案例围绕开篇提出的核心痛点展开，案例服务文章主题
3. 不刻意做大模型预期管理，教程本身就是为了解决文章开头抛出的用户痛点

## 🎯推文选题判断逻辑（产品缺少用户留言反馈，没有直接用户诉求）

三选一优先级：
1. 集市下载热度高的热门智能体，做推广教程
2. 内部提出需要推广的新上线智能体
3. 自己实操完成、体验效果好的自制智能体

## 🔁推文产出之后的价值闭环判断（重点，产品思维沉淀）

> 缺少用户留言反馈，依靠两类数据做判断
1. 数据指标：推文阅读量；对比不同智能体推文的数据表现（例：短视频脚本生成器阅读量显著高于简历生成器）
2. 产品侧热度：对应智能体平台内部实际使用热度

### 两种后续处理路径

1. 如果文章阅读高 + 对应智能体使用热度高：
   - 梳理【踩坑模块】反复出现的问题；
   - 区分三类问题：用户不会操作（已经在推文完成教育） / 产品功能缺陷（输出需求文档） / 大模型本身固有局限（教程内提示，不做产品迭代）
2. 如果阅读低、智能体使用热度低：判断该方向用户需求弱，不产出相关产品需求。

## ✅写作注意事项

1. 写作视角：以普通高频使用者第一人称切入，把熟练操作拆解为细粒度步骤，保证小白看下来步骤连贯，没有跳跃、没有晦涩干货。
2. AI生成稿件仅作为初稿，必须人工校对，还原个人写作口吻，修正步骤逻辑。
3. 图片素材：每一步操作都有对应截图，图片命名和步骤一一对应。
