# 🐾 桌面宠物生成器 v3.0 操作手册
> 详细使用指南，让您快速上手！
---
## 📥 安装说明
### Windows 系统
1. 双击 **`桌面宠物生成器-3.0.0-win-x64.exe`** 安装包
2. 点击「下一步」→「我接受」→ 选择安装目录
3. 点击「安装」，等待完成
4. 安装完成后，桌面会出现 **「桌面宠物生成器」** 快捷方式
### macOS 系统
1. 双击 **`桌面宠物生成器.app`**
2. 首次打开若提示「无法验证开发者」，请到 **系统偏好设置 → 安全性与隐私** 点击「仍要打开」
### 免安装版（绿色版）
- 解压 **`win-unpacked.zip`**，双击 **`桌面宠物生成器.exe`** 即可运行
---
## 🚀 快速上手
### 第一步：启动应用
双击桌面快捷方式或 `桌面宠物生成器.exe`，打开配置面板。
### 第二步：上传宠物图片
1. 点击 **「点击或拖拽上传宠物图片」** 区域
2. 选择一张宠物图片（支持 **PNG / JPG / GIF**）
3. 应用自动去除背景，生成透明宠物形象
4. 上传成功后显示图片预览
### 第三步：个性化设置
| 设置项 | 说明 |
|--------|------|
| **宠物名称** | 输入宠物名字，显示在状态栏 |
| **宠物大小** | 拖动滑块调整大小（40px - 200px） |
| **移动速度** | 慢速 🐢 / 中速 🐇 / 快速 🚀 |
| **宠物性格** | 活泼 ⚡ / 温和 🌿 / 慵懒 😴 |
### 第四步：启动宠物
点击 **「启动宠物」**，宠物开始在桌面上活动！
---
## 🎮 操作指南
### 宠物控制
| 操作 | 说明 |
|------|------|
| **启动宠物** | 宠物开始在桌面活动 |
| **停止宠物** | 暂停所有动作 |
| **重置位置** | 宠物回到屏幕中央 |
| **导出配置** | 导出宠物配置为 JSON 文件 |
### 鼠标交互
| 操作 | 效果 |
|------|------|
| **点击宠物** | 宠物开心跳跃 + 爱心特效 |
| **拖拽宠物** | 按住宠物拖到任意位置 |
| **悬停宠物** | 宠物看向鼠标方向 |
### 多宠物管理
- 点击 **「+ 添加宠物」** 添加新宠物（最多 5 个）
- 使用 **宠物选择器** 切换当前编辑的宠物
- 点击 **「移除宠物」** 删除宠物
### 深色模式
- 点击右上角 **「🌙 深色模式」** 按钮切换主题
- 应用会记住你的选择，下次启动自动恢复
### 系统托盘
- 宠物窗口关闭后，应用仍在系统托盘运行
- 右键托盘图标可 **打开配置面板 / 退出应用**

## ⚙️ 常见问题
### Q1: 宠物不显示？
- 检查是否点击了 **「启动宠物」**
- 检查宠物是否被 **「隐藏」**（点击眼睛图标显示）
- 检查宠物图片是否上传成功
### Q2: 背景去除不干净？
- 尽量选择主体清晰、与背景对比明显的图片
- 避免使用与主体颜色相近的背景
- 白色背景效果最佳
### Q3: 宠物不动？
- 确认宠物处于 **「运行中」** 状态
- 检查是否被 **「停止宠物」** 暂停
- 尝试点击 **「重置位置」**
### Q4: 如何卸载？
- **Windows**：控制面板 → 程序和功能 → 卸载「桌面宠物生成器」
- **macOS**：将 `桌面宠物生成器.app` 拖入废纸篓
